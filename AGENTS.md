# Tsudoi — вход для агентов

**Tsudoi** (集い, «встреча») — мессенджер для небольшой компании с закрытой регистрацией. Начальная аудитория — 3–5 постоянных участников. [Видение продукта](.ai/vision.md)

## Текущее состояние

Есть заготовка для разработки и локального запуска на Node.js 24 LTS, npm workspaces, TypeScript, React + Vite и Fastify. За открытие MVP отвечает задача [01. Первая версия мессенджера](.ai/features/01-mvp/README.md). Она на стадии `product`. Текущий объём работы — заготовка и продуктовая постановка. Переход к реализации требует явного сигнала владельца.

| Зона | Карточка |
|---|---|
| Окружение, запуск и проверка | [dev-env](.ai/map/dev-env.md) |
| Архитектура и границы пакетов | [architecture](.ai/map/architecture.md) |

## Как ведём задачи

Бриф → продукт → техника → план → реализация и проверки → проверка владельцем → вливание через PR. У задач с треком `tech` продуктовую стадию пропускаем. Папка задачи `.ai/features/NN-slug/` хранит документы и статус в `README.md`. Структура знаний следует образцу Hibiki. [Индекс знаний](.ai/README.md)

После согласования продукта подготавливаем технику. Явный сигнал «начинай реализацию» разрешает технику, план и код в согласованном объёме. Для merge требуется «принято», «вливай» или отдельное разрешение вести задачу автономно.

Первичную основу и постановку `01-mvp` публикуем в `main` по поручению владельца. Продолжение задачи ведём в `codex/01-mvp`. Для последующих задач используем ветки `codex/NN-slug`.

## Правила проекта

- Документы и общение — по-русски. Код, идентификаторы и conventional commits — по-английски.
- Материалы задач живут в `.ai/`. Карточки карты отражают фактическое состояние. Обновляй карточку вместе с изменением соответствующей зоны. Влитые задачи храним как архив.
- Публичный репозиторий содержит исходники и документацию. `.env`, рабочие БД, файлы пользователей, инвайты, токены и материалы ручной проверки храним локально вне git.
- Доступ к чату, сообщениям, событиям и вложениям определяется членством. Гостевой доступ ограничен конкретным чатом и временем действия.
- Перед запуском проверь порты. Текущее окружение и подтверждённые команды описаны в [dev-env](.ai/map/dev-env.md).
