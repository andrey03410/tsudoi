# Tsudoi · 集い

Мессенджер для небольшой компании с регистрацией по приглашениям. Первая версия рассчитана на 3–5 постоянных участников и гостей отдельных групп.

Личные диалоги, группы, история и непрочитанное. Участники могут отправлять текст, стикеры, GIF и файлы, добавлять и снимать реакции. Гость входит по одноразовой ссылке и видит переписку с момента вступления. Связь восстанавливается через WebSocket и журнал изменений. [Постановка MVP](.ai/features/01-mvp/product.md)

## Локальный запуск

Понадобятся Node.js 24 LTS (от 24.11) и npm. Если нужны собственные порты или каталог данных, скопируй [`.env.example`](.env.example) в `.env` и выбери значения до создания администратора. Из корня репозитория выполни

```sh
npm ci
npm run admin -- --login owner --display-name 'Моё имя'
npm run dev
```

Команда `admin` один раз создаёт администратора и запрашивает пароль со скрытым вводом. Страница разработки доступна по адресу [127.0.0.1:5175](http://127.0.0.1:5175), сервер — по [127.0.0.1:8791/health](http://127.0.0.1:8791/health). Войди как администратор и открой «Приглашения», чтобы создать аккаунты для участников.

Для локального запуска собранной версии останови `dev` и выполни

```sh
npm run build
npm start
```

Fastify раздаёт собранную страницу на [127.0.0.1:8791](http://127.0.0.1:8791). База и медиа хранятся в `storage/`. Для хостинга настрой HTTPS перед Fastify и укажи внешний адрес в `TSUDOI_ORIGIN`. Прокси должен пропускать WebSocket на `/ws`. [Настройки, миграции и бэкап](.ai/map/dev-env.md)

## Проверки

```sh
npm test
npm run build
npm run typecheck
npx playwright install chromium webkit
npm run test:e2e
```

Playwright использует актуальную сборку и отдельные временные данные. Два проекта проверяют настольный Chromium и WebKit с параметрами iPhone. [Приёмка MVP](.ai/features/01-mvp/verify.md)
