# Tsudoi · 集い

Мессенджер для небольшой компании с регистрацией по приглашениям. Первая версия рассчитана на 3–5 постоянных участников и гостей отдельных чатов.

Продуктовая постановка первой версии открыта для согласования. В репозитории можно запустить базовую страницу и серверную проверку `/health`. [Постановка MVP](.ai/features/01-mvp/product.md)

## Локальный запуск

Понадобятся Node.js 24 LTS (от 24.11) и npm. Для запуска с настройками по умолчанию достаточно выполнить из корня репозитория

```sh
npm ci
npm run dev
```

Страница разработки доступна по адресу [127.0.0.1:5175](http://127.0.0.1:5175), сервер — по [127.0.0.1:8791/health](http://127.0.0.1:8791/health). Для собственных портов создай `.env` по образцу [`.env.example`](.env.example).

Для локального запуска собранной версии останови `dev` и выполни

```sh
npm run build
npm start
```

Fastify раздаёт собранную страницу на [127.0.0.1:8791](http://127.0.0.1:8791). `npm run typecheck` проверяет TypeScript во всех рабочих пакетах. [Окружение и проверки](.ai/map/dev-env.md)
