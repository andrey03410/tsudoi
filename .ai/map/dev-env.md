# Окружение и проверка

Из корня репозитория используй Node.js 24 LTS от 24.11 и `npm ci`. В платформенном менеджере версий ориентируйся на [`.node-version`](../../.node-version). Настройки из [`.env.example`](../../.env.example) можно скопировать в локальный `.env`.

| Команда | Результат |
|---|---|
| `npm run dev` | Fastify на `127.0.0.1:8791` и Vite на `127.0.0.1:5175`, перезапуск сервера при изменении TypeScript. |
| `npm run build` | Компилирует сервер в `apps/server/dist`, собирает веб-клиент в `apps/web/dist`. |
| `npm start` | Fastify раздаёт сборку на `http://127.0.0.1:8791`. Перед запуском освободи порт, остановив `dev` Tsudoi. |
| `npm run typecheck` | Проверяет TypeScript рабочих пакетов. |

На macOS перед запуском можно проверить порты командой `lsof -nP -iTCP:8791 -iTCP:5175 -sTCP:LISTEN`. Если порт занят соседним проектом, задай свой `TSUDOI_PORT` или `TSUDOI_WEB_PORT`. `TSUDOI_HOST` меняет bind-адрес Fastify. При локальной разработке Vite обращается к Fastify через `127.0.0.1`.

Для проверки заготовки собери проект, проверь типы и сделай HTTP-запросы к `/` и `/health` в dev и в собранной версии. Ожидаются страница Tsudoi и `{"status":"ok"}`. [Скилл verify](../../.claude/skills/verify/SKILL.md)
