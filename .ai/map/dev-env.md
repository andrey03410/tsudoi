# Окружение и проверка

Из корня репозитория используй Node.js 24 LTS от 24.11 и `npm ci`. В платформенном менеджере версий ориентируйся на [`.node-version`](../../.node-version). Настройки из [`.env.example`](../../.env.example) можно скопировать в локальный `.env`.

| Команда | Результат |
|---|---|
| `npm run admin -- --login owner --display-name 'Моё имя'` | Создаёт первого администратора. Пароль запрашивается без эха. В автоматизации можно передать пароль по стандартному вводу. |
| `npm run dev` | Fastify на `127.0.0.1:8791` и Vite на `127.0.0.1:5175`. TypeScript-сервер перезапускается при изменении приложения. |
| `npm run build` | Компилирует сервер в `apps/server/dist`, собирает веб-клиент в `apps/web/dist`. |
| `npm start` | Fastify раздаёт сборку на `http://127.0.0.1:8791`. Перед запуском освободи порт, остановив `dev` Tsudoi. |
| `npm run db:generate` | Генерирует Prisma Client после изменения `schema.prisma`. При `npm ci` выполняется автоматически. |
| `npm test` | Интеграционные тесты Fastify и SQLite во временных папках и клиентские тесты синхронизации. |
| `npm run typecheck` | Проверяет TypeScript рабочих пакетов. |
| `npm run test:e2e` | Запускает собранную версию со временной БД и проверяет её в Chromium и WebKit. Браузеры ставятся через `npx playwright install chromium webkit`. |

На macOS перед запуском можно проверить порты командой `lsof -nP -iTCP:8791 -iTCP:5175 -sTCP:LISTEN`. Если порт занят соседним проектом, задай свой `TSUDOI_PORT` или `TSUDOI_WEB_PORT`. `TSUDOI_HOST` меняет bind-адрес Fastify. При локальной разработке Vite обращается к Fastify через `127.0.0.1`.

## Данные и хостинг

`TSUDOI_STORAGE_DIR` задаёт каталог данных. По умолчанию это `storage/` из текущей рабочей папки. При запуске приложение применяет SQL-миграции из `apps/server/prisma/migrations/` по порядку `user_version`. Резервную копию делай после чистой остановки сервиса, копируя весь каталог данных в отдельное место. Для переноса восстанови его до запуска нового экземпляра.

Для HTTPS за обратным прокси установи `TSUDOI_ORIGIN` в фактический внешний адрес, например `https://chat.example.org`. Этот адрес используется для проверки Origin и включает Secure cookies. Укажи IP или сеть своего прокси в `TSUDOI_TRUST_PROXY`, чтобы лимиты входа применялись по IP клиентов. Допустим список через запятую. Прокси перенаправляет обычные запросы и WebSocket на `/ws` на локальный порт Fastify. `GET /health` проверяет, что процесс отвечает.
