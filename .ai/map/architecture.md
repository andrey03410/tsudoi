# Архитектура

## Что есть сейчас

| Зона | Содержимое |
|---|---|
| `apps/web` | React-страница с именем проекта и Vite для разработки и сборки. Vite проксирует `/health` на локальный Fastify. |
| `apps/server` | Fastify, `GET /health`, старт собранной версии с раздачей статических файлов. |
| `packages/contracts` | Зарезервированный workspace для общих HTTP- и WebSocket-контрактов. |

Предложенное направление для первой реализации — единый Node-сервис, SQLite через Prisma, локальные вложения, HTTP для команд и истории, WebSocket для событий. Технические решения, схема и маршруты появятся на стадии `tech` задачи. [01-mvp](../features/01-mvp/README.md)
