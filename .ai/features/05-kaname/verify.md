# Приёмка

Результаты интеграционной проверки, сборки, типизации, браузерного входа и работающего релиза вносятся по мере выполнения.

## Независимое ревью и локальная проверка

Проверены интеграция относительно origin/main, новый SDK, миграции и пути доступа к чатам, гостям, событиям, вложениям и административным формам. Пара issuer/subject определяет личный профиль, выборки панели и статистику. В production-сборке ссылки гостей теперь учитывают KANAME_GUESTS во время выполнения. Разрешённый гость видит текстовое поле и может написать в свою группу. Сервер проверяет запреты на загрузки, стикеры и реакции. Учётные записи другого issuer исключены из выбора получателей. При загрузке сервер повторяет проверку доступа и квоты перед сохранением вложения. Логи HTTP не включают параметры callback с одноразовым кодом.

В Node 24.21.0 последовательно выполнены npm test (27 из 27), npm run build и npm run typecheck. Интеграционная проверка использовала временную SQLite и отдельный локальный HTTP-сервер назначений. При параллельной попытке занять последнее место для группы один запрос прошёл, второй получил 409. Проверены включение приглашений после отказа с выключенным гостевым флагом, реальное использование одноразового приглашения, отправка гостевого текста, запреты на стикеры и реакции, отзыв назначения и изоляция одного subject в разных issuer. В тестах исходящего WebSocket и файлов сохранились проверки membership, видимой истории и отзыва.

Сквозной вход с промышленным Keycloak, живую приёмку в браузере, SHA и запуск на VPS подтверждает координатор общей выкладки.
