# Техническое решение

После открытия WebSocket сервер повторно определяет участника при подключении, в heartbeat и перед отправкой события. Если право отозвано, сервер закрывает соединение кодом 4001. При временной ошибке проверки сервер закрывает конкретный сокет кодом 1013 и продолжает обход. Получатели проходят собственную проверку сессии и доступа к чату.
