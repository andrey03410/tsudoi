# Приёмка

На macOS с Node.js 24 и временной SQLite регрессионный тест подключил настоящие WebSocket постоянного участника и гостя. До исправления второй вызов рассылки истекал по таймауту. После исправления постоянный участник при ответе Kaname 503 не получил событие, его соединение закрылось кодом 1013. Гость с действующим членством получил обновление этого же чата.

- `npm test` — 28 из 28.
- `npm run build` — сервер и Vite-клиент собраны.
- `npm run typecheck` — успешно.
- `npm run test:e2e` — 4 из 4, настольный и мобильный браузеры. Проверены синхронизация после переподключения и перезапуска, а также отзыв гостевого доступа в открытой вкладке.

Тест имитирует ответ сервиса проверки прав и использует живые соединения с локальным экземпляром Tsudoi.
