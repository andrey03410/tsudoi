# Техническое решение

Общая директива `basic_auth` в `deploy/Caddyfile` отвечает за браузерное окно. Удаляем её, сохраняя маршрутизацию к четырём контейнерам, HTTPS, проверки Origin и проксирование токенов на специализированных маршрутах. Каждый образ продолжает работать с `PROVISIONED_ACCOUNTS_ONLY=1`.

До переключения устанавливаем случайный пароль в каждой существующей учётной записи, через stdin и хеширование по правилам приложения. Пароли сохраняются в локальном файле вне репозиториев. Резервные копии SQLite хранятся на VPS. Перед загрузкой Caddy проверяем вход с новыми паролями.
