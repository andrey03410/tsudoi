# Техническое решение

Общий Compose в deploy/compose.yaml запускает отдельный воркер из образа Hibiki через Docker init. Проверяем аргументы дочернего процесса init через Linux /proc. HTTP-проверку сохраняем у самого Hibiki. Воркер станет healthy при работающем процессе с ожидаемой точкой входа; smoke не требует создания фонового задания.

При одновременной выкладке общая блокировка ждёт до 10 минут. При старте Douga скачивание холодного образа заняло больше исходных 90 секунд и прервало параллельную выкладку Hibiki. Тайм-аут теперь возвращает понятное сообщение.
