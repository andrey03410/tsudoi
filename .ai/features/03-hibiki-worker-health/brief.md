# Проверка воркера Hibiki при деплое

Docker Compose запустил воркер, затем завершил release с ошибкой `has no healthcheck configured`. Из-за этого успешный запуск не зафиксирован в `images.env`. Нужно, чтобы первый и последующие релизы Hibiki проверяли основной процесс воркера и фиксировали активный тег.

Автономный режим. «Все правки в репах делай через /feature автономно вплоть до подлива в main и конечного деплоя».
